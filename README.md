# Rede Acolher - Site Institucional e Educativo

Este projeto é uma **Atividade Curricular de Extensão** do curso de **Análise e Desenvolvimento de Sistemas da UNIASSELVI**, alinhado ao **ODS 16 da ONU (Paz, Justiça e Instituições Eficazes)**.

O objetivo do site é conscientizar sobre a violência doméstica, explicar os direitos previstos na Lei Maria da Penha e facilitar o acesso à rede local de proteção social.

---

## 🛠️ Tecnologias Utilizadas
- **React 18** com **TypeScript**
- **Vite** (Build Tool rápida e leve)
- **CSS3** com Variáveis Globais e Modularização (Acessibilidade WCAG 2.2 AA)
- Sem dependências externas pesadas ou bibliotecas de UI genéricas.

---

## 🚀 Como Executar o Projeto Localmente

1. **Clonar ou baixar os arquivos do projeto.**
2. **Instalar as dependências:**
   ```bash
   npm install
   ```
3. **Iniciar o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

Para gerar a versão de produção:

```bash
npm run build
```

O projeto também possui publicação automática no GitHub Pages por meio do workflow em `.github/workflows/deploy.yml`.
